# TextileDemand AI

A planned end-to-end demand forecasting project for a hypothetical textile manufacturer.

## Structure
- `data/raw/`: original datasets (keep source files unchanged)
- `data/processed/`: cleaned datasets
- `notebooks/`: exploratory analysis
- `src/`: preprocessing, feature engineering, training, evaluation and prediction code
- `models/`: saved trained models
- `dashboard/`: Streamlit application
- `reports/`: project reports and outputs

## Getting started
Create and activate a virtual environment, then install dependencies:
```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
```

The source files are starter placeholders; we will implement them step by step.
